One row, a few ways

Every option puts the input on one row with nothing above it. They differ in two ways: how they show the window behind Script Kit, and where they report what just happened. Pick a preset, or mix the two choices yourself. Switching keeps whatever you typed.

    Try it

    • Type remind me to call mom tomorrow at 5pm, press ↵, then ⌘Z. Watch where the presets report the run and its undo.
    • In A sentence to try, press Tab on the empty input to take the suggestion. Its faint underlines use the same colors as the word marks, so you can see what each phrase does before you type one.
    • Click the icon at the start of the input, or press Space on an empty input, to act on that window. Esc lets go.
    • Type empty trash and press ↵ to see a run that waits eight seconds. ⌘Z on an empty input stops it.
    • Hold ⌘ to see every key where it works.

    Browsers keep some shortcuts for themselves. If ⌘1 switches tabs, click the row instead. Single-click selects a row; double-click or ↵ runs it.
