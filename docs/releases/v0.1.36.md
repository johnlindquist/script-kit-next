# Script Kit 0.1.36 · Find it, edit it, undo it

Type the full name of an installed app to make it the Return action. A later suggestion won’t take over a row you chose yourself. If you select your whole query and type a replacement, one ⌘Z restores the original query. Redo restores the replacement.

Try these in the launcher:

- Type **keyboard shortcuts** to find the guide to keys, symbols and views.
- Type **emoji mushroom** to see a matching emoji and the Emoji Picker. Nothing is pasted while you search.
- Highlight **Agent Chat**, press ⌘K, and choose **See past chats** to browse earlier conversations without starting a new one.
- Search for **snippet** to find the scriptlet bundle template. It includes a reusable greeting you can edit.
- With text selected, type **Translate to French** to send the instruction and selection together. With nothing typed, ⌘Return opens a clean chat.

Missing Accessibility and Screen Recording permissions appear under **Needs setup** on a fresh workspace. Select a permission to review it, or choose **Continue without them**. You can revisit all five under **Set Up Permissions**. Moving a note to the Trash offers Undo for that note; an old Undo can’t overwrite a later edit.
