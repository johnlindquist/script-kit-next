# Script Kit 0.1.35 · Launcher search and setup

Type an installed app’s full name to make it the Return action, even if a similarly named script or a slower suggestion appeared first. Once you move the selection yourself, later results leave it alone.

With text selected, type **Translate to French** to send the instruction and the selection together. With nothing typed, ⌘Return still opens a clean chat.

On a fresh workspace, missing Accessibility and Screen Recording permissions appear under **Needs setup**. Select a permission to review it, or choose **Continue without them**. Kit remembers that choice. Type **Set Up Permissions** to revisit all five later.

Moving a note to the Trash offers Undo for that specific note. An old Undo cannot replace a newer edit.
