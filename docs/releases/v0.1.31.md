# Script Kit 0.1.31 · Tell Kit how you want the launcher to work

Type **Customize Kit** for editable examples. Try **Keep my launcher minimal** for an uncluttered scripts-only home, or **Make a list of my pinned notes called Reading shelf**. After saving the list, type **view reading shelf**. Return opens the selected note; Escape restores the list and its filter. If the note has changed or no longer qualifies, Kit asks you to choose again. Your apps, scripts and notes stay where they are.

Type **Make the pinned label brighter** in Kit. Under **Customize Kit**, select **Use brighter text for Stays open** and press Return to save it. Pin the window with ⌘⇧P. Only the label changes. To keep the brighter color but change its weight during recording, type **Make the pinned label bold only while dictating** and review that row before pressing Return. These phrases work offline. Dictating the same words into another app does not apply them.

**Put today’s note first for selected text** changes the first action on the Selection tab. Saving this preference does **not** save your selection. Choose Selection and run **Add selection to today’s note** when you want to save the passage. Clipboard keeps its own action order.

To find out where a rule came from, ask **Why is the pinned label brighter?** To reverse the most recent launcher change, type **Undo my last launcher change**. **Disable my launcher customizations** returns to stock behavior without deleting the rules; **Enable my launcher customizations** turns them back on. Undoing an action preference does not undo a note you already saved.

## Preview a change from an agent

With Kit running and Bun on PATH, set `SCRIPT_KIT_AGENT_CREDENTIAL` in the agent’s shell to its private `launcher:read` credential file for this workspace. Use the workspace’s `bin/scriptkit` if `scriptkit` is not on PATH. To preview the Selection change:

```sh
printf '%s\n' '{"change":{"op":"edit","edit":{"target":"launcher.subject.selection.firstAction","value":"note"}}}' |
  scriptkit agent launcher preview
```

In the JSON reply, `data.scope` should be `"preview"` and `data.wouldStore.declared.selectionFirst` should be `"note"`. A preview does not change your rules or save any selected text. Do not grant write access or use an operator credential just to preview. The `scriptkit --skill` manual explains setup.

A configured launcher author can also propose a personal list. Check `views.schema` in `scriptkit agent launcher describe` before asking for one. A list of pinned note titles does not grant access to terminal panes. For a read-only pane list, [pair one local Herdr space](../guides/personal-launcher.md#share-a-read-only-herdr-pane-list) first. Only the Kit workspace that made the offer can pair it. To stop sharing, the operator can withdraw the exact offer without deleting files or disturbing a newer share. Unpairing also detaches Kit and discards a late read. A pane can report that it needs attention without sharing its title or terminal output. Selecting it does not focus or zoom it. For a novel request, type **Customize Kit:** followed by your words. **Review request** opens an unsent draft only with the selected launcher-only profile. In a dedicated author chat, check the target, condition and value before choosing **Save once** or **Don’t save**. That chat prompt is not a second confirmation for an external credential with `launcher:apply`.

If a save reply is lost, check its original request ID in the same workspace instead of sending another edit. `committed` means the request is in the active history, not that an open window has adopted it. Moving the rules file aside can leave an old request outside the active history. That is not an instruction to replay it. `scriptkit agent launcher live` reports what the window adopted; it does not prove that a note was saved or a pane focused.

For installation, use the signed **Script-Kit-macos.zip** on this GitHub release, not the source archive. Keep your existing Kit workspace when upgrading. See the [personal launcher guide](../guides/personal-launcher.md) for Undo, safe mode, sharing a read-only pane list and planning a separate native candidate.
