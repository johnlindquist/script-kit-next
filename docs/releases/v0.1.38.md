# Script Kit 0.1.38 · Local previews

Type **QR code**, press Return, and enter the words you want to encode. Scan the preview or choose **Copy QR as SVG**. Text stays in the local QR tool. **Palette** shows five labeled tones of a hex color without changing your theme.

- **Metronome 120** opens a silent four-beat display at 120 BPM. Press Return to start or stop. Changing the tempo stops the beat; valid tempos are 30–240 BPM.
- **Roll 2d8** offers a pair of eight-sided dice. Press Return to roll; the answer shows the individual faces and their sum. Typing alone never rolls.
- With text selected or a clipping chosen, try **slug**, **reverse**, **reading time**, **markdown**, **whitespace**, or **Base64**. Review the result before copying anything. Reading time assumes 200 words per minute. Base64 is an encoding, not encryption.
- Sort lines, remove duplicates, or compare the selected and copied text locally. A note search can show the matching body line. When you return from a day-page fragment, the editor locates its reference when it can do so unambiguously.
- **Days until** opens an editable date query. **Speak** offers the existing `say()` command documentation; opening it does not play audio.
