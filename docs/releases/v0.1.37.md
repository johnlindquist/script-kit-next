# Script Kit 0.1.37 · Local tools and editing

Type **5 minute timer** and press Return to start a countdown while Script Kit is running. You can stop it and use Undo to resume. **Flip a coin** or **random number between 4 and 7** offers a draw; simply typing the request does not draw a result.

- **two miles in kilometers** displays **3.218688 km**. With text selected, **word count** and **title case** give local answers without editing the selection or sending it to a model.
- Choose **large type** and type a cue to show it in large text. **color #63B7A6** previews a swatch without changing your theme. A lone **#** still starts a note.
- In Today, Return at the end of a Markdown checklist item starts an unchecked item. Return again on its empty marker to leave the list. Control-T swaps adjacent characters; at the end of a line it swaps the final pair. Use **Previous day** in the daily page’s actions. On a past page, **Next day** takes you back toward today.
- In a form, Command-Z and Shift-Command-Z act on the focused field. Command-Left and Command-Right move to the ends of the current line. Leaving a changed, invalid email field shows its validation message without submitting the form.
- In Apps, abbreviations can match the beginnings of multiple words. Actions on an app belong to that app. In the emoji grid, Home and End go to the first and last emoji.
