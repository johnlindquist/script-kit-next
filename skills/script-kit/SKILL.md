---
name: script-kit
description: Use Script Kit when the person asks for a desktop note, a handoff of explicitly shared text, an editable reply, or a reviewed personal command. Not for ordinary shell work or general control of their keyboard, mouse or clipboard.
---

Read `scriptkit --skill` first (also available as `~/.scriptkit/bin/scriptkit --skill`). This reads the installed manual without opening the app. Use `scriptkit agent discover` with the agent credential the person provided. Never substitute the operator’s token, install grants yourself, or open the window just to discover capabilities. If the app or grant is unavailable, report that prerequisite. Read back the addressed result before claiming delivery.
